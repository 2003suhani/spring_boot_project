# Spring Boot Project

## Project Overview

This project is a Java Spring Boot application developed using a layered architecture.

The application is organized into different packages to separate responsibilities and maintain clean and structured code.

## Technologies Used

- Java
- Spring Boot
- Spring Framework
- REST APIs
- JPA / Hibernate
- MySQL
- Maven
